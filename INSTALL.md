# Установка — по шагам, с нуля (macOS)

Ничего знать заранее не нужно. Всего четыре шага, вместе — минут 15.
Один раз придётся открыть Терминал и вставить туда строчку. Это не страшно:
вставить и нажать Enter.

---

## Шаг 0. Подписка

Claude Code работает только на платном тарифе **Pro** или **Max**
(бесплатный claude.ai не подходит). Если подписки нет — оформить тут:
[claude.ai/upgrade](https://claude.ai/upgrade). Pro хватает с запасом.

Запомни email и пароль аккаунта — они понадобятся на шаге 1.

---

## Шаг 1. Поставить Claude Code

Два пути. **Выбери первый, если не любишь терминал.**

### Путь А — приложение (рекомендую)

1. Скачай: [**Claude Code для macOS**](https://claude.ai/api/desktop/darwin/universal/dmg/latest/redirect)
2. Открой скачанный `.dmg` и перетащи приложение в «Программы».
3. Запусти, войди в аккаунт из шага 0.

Это обычное приложение с окном — терминал для работы не нужен.

### Путь Б — терминал

Открой Терминал (⌘ + пробел → набери `Терминал` → Enter), вставь и нажми Enter:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Пока команда работает, ничего не показывается — это нормально, подожди.
Потом закрой окно Терминала, открой новое и проверь:

```bash
claude --version
```

Должен появиться номер версии. Первый запуск — команда `claude`, дальше вход
через браузер.

---

## Шаг 2. Скачать этот набор

На странице репозитория: зелёная кнопка **Code** → **Download ZIP**.
Скачается архив в «Загрузки» — кликни по нему два раза, он распакуется в папку.

> Если страница говорит «404» — значит, доступ ещё не выдан. Напиши Данилу,
> он добавит твой GitHub-аккаунт в репозиторий.

---

## Шаг 3. Установить скилл

Открой Терминал (даже если на шаге 1 выбрала приложение — это один раз).
Перетащи распакованную папку прямо в окно Терминала — он сам подставит путь.
Должна получиться такая строка:

```bash
bash /Users/ТВОЁ_ИМЯ/Downloads/smm-starter-main/install.sh
```

Нажми Enter. Скрипт напишет, что он сделал. В конце — зелёная галочка.

**Что он делает (ничего не удаляет):**

- кладёт скилл `profile` в `~/.claude/skills/profile/`;
- создаёт рабочую папку `~/Documents/SMM/` с подпапками `profile/`,
  `content/`, `references/`;
- кладёт туда `CLAUDE.md` — инструкцию, которую Claude читает автоматически.

---

## Шаг 4. Первый разговор

**Если приложение (путь А):** открой Claude Code, выбери папку
`Documents/SMM` как рабочую.

**Если терминал (путь Б):** вставь в Терминал:

```bash
cd ~/Documents/SMM && claude
```

Дальше в чате напиши:

```
давай профиль
```

Начнётся интервью — по одному вопросу за раз. Отвечай как говоришь, можно
диктовкой, можно сбивчиво: он вытащит смысл. В конце он сам соберёт заметку
и положит в `profile/`.

**Первая заметка — `identity`, вторая — `taste`.** Вот `taste` и есть та самая,
из-за которой дизайн потом будет твой, а не «как у всех». К ней стоит заранее
накидать в папку `references/` скриншоты визуала, который нравится — и сказать
в чате, что они там лежат.

---

## Если что-то не так

| Симптом | Что делать |
|---|---|
| `command not found: claude` | Закрой окно Терминала и открой новое. Не помогло — запусти `bash ~/.local/bin/claude doctor` |
| `permission denied` на install.sh | Запускай именно через `bash путь/install.sh`, а не кликом по файлу |
| Скилл не срабатывает на «давай профиль» | Перезапусти Claude Code. Проверь, что файл на месте: `ls ~/.claude/skills/profile/` |
| Отвечает по-английски | Напиши «отвечай по-русски» — и попроси дописать это в `CLAUDE.md` |
| Всё сломалось | Напиши Данилу, не чини вслепую 🙂 |

---

## Обновление

Пришла новая версия набора — скачай ZIP заново и прогони `install.sh` ещё раз.
Твои заметки в `~/Documents/SMM/` он не тронет, а старую версию скилла отложит
в папку с пометкой `.backup-<дата>`.
